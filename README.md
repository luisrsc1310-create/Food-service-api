# Food Service API

## -> Features 
- Food CRUD
- Page for create Foods and Orders
- Category system
- Order system (with OrderItem)
- Filter systems

## -> Technologies used
- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- PostgreSQL
- PostMan for Tests


## -> How to run this project?
1. Clone repo
2. Run application
3. Access: http://localhost:8080
